# Roadmap 🚀

The future vision for GitPatrol is to become a robust "Code Insurance" platform for critical open-source assets.

## 🏁 Phase 1: High-Performance Backend (Current)
- [x] Multi-provider abstraction (`GitHub`, `GitLab` support).
- [ ] Transition from Git CLI to `go-git` library.
- [ ] Metadata extraction for Issues, Wikis, and Releases.
- [ ] Enhanced health scores based on long-term commit frequency.

## 🏁 Phase 2: Code Insurance & Context
- [ ] Archiving Issues/PRs as local JSON (searchable in dashboard).
- [ ] Automated Wiki mirroring (`.wiki.git`).
- [ ] Advanced filtering (stars, activity, language).
- [ ] Multi-destination support (Off-site S3 backup).

## 🏁 Phase 3: Analytics & Integration
- [ ] Visual dependency graphs.
- [ ] Multi-user support with read-only dashboard.
- [ ] Webhook triggers for third-party tools.
- [ ] E-mail and Slack/Telegram notifications for health alerts.
